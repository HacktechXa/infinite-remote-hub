# 小米蓝牙遥控器 2 Pro

型号 ID：`xiaomi-2-pro`。HID 厂商 `0x2717` / 产品 `0x32B8`。包格式 v2，发布版本 `1.0.0`。

## 配对与检查

1. 在 Mac 的系统设置 → 蓝牙中配对。
2. 授予无限遥控器输入监控；系统快捷键和辅助功能动作需要辅助功能权限。
3. 检查按下、松开及当前动作。打开诊断时不会执行无限遥控器自身的配置动作。
4. ChatGPT 听写快捷键设为 F5；语音键由 ChatGPT 原生接收。应用不采集遥控器麦克风音频，NFC 标签未接入。

应用首次安装不内置真实型号。请在资源库安装此型号，或用“导入型号包…”直接选择 ZIP，也支持选择包含 manifest.json 的文件夹。同来源更高 release 可以更新已安装型号；其他来源不能覆盖，更新保留用户映射。

默认动作：电源短按切换屏幕、长按锁屏；语音触发听写；方向和确认发送方向键及 Return；返回发送 Esc；主页激活默认目标应用（初始为 Codex）；音量加减调整系统音量；菜单打开运行中应用选择器；直播打开媒体应用选择器。可以在应用中修改映射。
